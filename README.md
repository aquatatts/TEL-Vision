# TEL-Vision

Source of truth for the TEL Collection Shopify build (telcollection.com.au, theme: Prestige 11.4).

- `theme/` — snapshot of every theme file changed for the launch build ("TEL v6 — LAUNCH CANDIDATE"). Paths mirror the theme (`sections/`, `templates/`, `assets/`, `config/`, `layout/`). `theme/pages/` holds the HTML bodies of the custom pages (Our Aim, The Founder, Trusted By, FAQs, The Healing Guide).
- `images/web/` — 4000 px web versions of the new studio shoot, sized under Shopify's 25 MP limit. The full-resolution originals sit in the repo root.
- `LAUNCH.md` — the launch-day runbook and post-launch checklist.
